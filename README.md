# Trello × Google Calendar タスク振り分けルール

TrelloとGoogle Calendarへの二重登録を避けるための、AI向けタスク管理ルールです。  
日時未定のタスクと期限はTrello、実際に行う日時が決まった予定はGoogle Calendarを正本とします。  
AIは日付の意味を判定し、重複確認・登録・結果確認までを一貫して行います。

## 基本ルール

| 入力内容 | 正本 | 例 |
| --- | --- | --- |
| 日付のないタスク | Trello | 絵の具を買う |
| 期限だけがあるタスク | Trello | 9月20日までにイラストを完成させる |
| 実行日時が決まった予定 | Google Calendar | 9月5日9時に病院へ行く |
| 実行日が決まった既存カード | Google Calendarへ安全に移管 | 買い物を8月18日に行うと決めた |

> 期限は「その日までに終える日」、実行日は「実際に行う日」です。

同一案件でも、成果物の期限と作業日時は別の管理対象です。たとえば「9月20日までに完成」はTrello、「9月15日19時から仕上げ」はGoogle Calendarで管理できます。

## 特徴

- 同じ意味の情報を二重登録しない
- 期限だけではCalendarへ登録しない
- 登録前に重複候補を確認する
- Calendar登録を再確認できた後だけ、移管元カードをアーカイブする
- 推定値を正式な予定として勝手に補完しない
- 読み取り指示では外部データを書き換えない

## 使い方

1. [`task-routing-master.md`](./task-routing-master.md)をAIへ渡します。
2. 「この文書を、この会話のタスク管理ルールとして使用してください」と指示します。
3. 最初は読み取り専用で振り分け結果を確認します。
4. 問題がなければ、TrelloまたはGoogle Calendarへの登録を依頼します。

詳しくは[AIへの渡し方](./docs/ai-setup.md)と[振り分け例](./examples/routing-examples.md)を参照してください。

## 安全上の注意

- 外部サービスの変更には、対応する連携機能と権限が必要です。
- 連携不能時は別サービスへ代替登録せず、未登録として報告します。
- 削除・アーカイブ・大量変更は、対象と件数を確認してから実行します。
- APIキー、アクセストークン、個人情報、実在カードのURLやIDを公開リポジトリへ保存しないでください。
- この文書はAIの誤操作を完全に防止するものではありません。
