# AIへの渡し方

## 1. 文書を参照させる

`task-routing-master.md`を、ファイル添付、プロジェクトの知識領域、またはAIが参照できるリポジトリとして渡します。URLだけを渡す場合は、AIが実際にそのURLを読めることを確認してください。

## 2. 適用を指示する

```text
添付した task-routing-master.md を、この会話のタスク管理ルールとして使用してください。
登録前に日付が期限・開始日・実行日のどれかを判定してください。
同じ意味の情報をTrelloとGoogle Calendarへ二重登録しないでください。
外部サービスを変更した場合は結果を再確認し、確認できなければ成功扱いにしないでください。
```

## 3. 事前に決める項目

初回利用時に、次の項目を指定します。未指定の値をAIが正式値として推測してはいけません。

```text
タイムゾーン：Asia/Tokyo
Trelloボード：個人タスク
通常の追加先リスト：未着手
Google Calendar：予定
カードのアーカイブ：実行前に毎回確認
日付だけの予定：終日登録前に確認
```

## 4. 最初は読み取りで確認する

```text
次の3件をまだ登録せず、どちらで管理すべきか判定してください。
1. 絵の具を買う
2. 9月5日9時に病院へ行く
3. 9月20日までにイラストを完成させる
```

期待結果は順に、Trello、Google Calendar、Trelloです。

## 5. 登録を依頼する

```text
マスターのルールに従って登録してください。
登録前に重複を確認し、登録後に結果を再確認してください。
処理に必須の情報が不足している場合だけ確認し、必須でない項目は未設定のまま処理してください。
値を推測して正式登録しないでください。
```

## 6. 外部連携を準備する

実際の登録・変更には、対象サービスの連携機能が必要です。AIには対象ボードやカレンダーを識別するために必要な情報だけを渡し、認証情報をリポジトリへ保存しないでください。

削除、アーカイブ、大量変更を依頼する場合は、対象と件数を先に表示させてください。初回やルール変更後は、読み取り専用の判定から始めることを推奨します。
